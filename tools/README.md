# tools/

Scripts and small programs used to develop the project. Nothing here ships in the engine or
in exported games.

| Tool | What it does | Run it |
|---|---|---|
| `check_docs.py` | Checks that every `[S#]` citation is defined in `docs/sources.md` and used, and that relative Markdown links and heading anchors resolve | `python3 tools/check_docs.py` |
